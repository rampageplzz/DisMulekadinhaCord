Antes de instalar

O cliente ocupa aproximadamente 0,88 MiB, além do runtime WebView2 compartilhado, cache e perfil. O download adicional do runtime só ocorre quando ele não está instalado. Não há ainda comparação medida de memória com o Discord.

Esta é uma versão inicial, sem assinatura digital própria. O Windows pode mostrar um aviso de editor desconhecido. Você pode conferir o checksum SHA-256 e o código no GitHub.

Áudio e tela ainda precisam de validação entre dois computadores. Algumas redes exigem um servidor TURN. Ver recursos e limitações.
